# Dongwha Pharmaceutical — Design System

> 동화약품 웹사이트 리뉴얼 프로젝트의 메인 페이지(`index.html`)와 실제 적용 CSS를 기준으로 정리한 서브페이지 제작 가이드입니다.  
> 이 문서는 기존 메인 페이지의 디자인을 바꾸기 위한 문서가 아니라, 이후 서브페이지가 메인 페이지와 같은 시각 언어와 UI 규칙을 따르도록 돕는 기준입니다.

## 1. Project Overview

### 프로젝트 목적
- 동화약품의 브랜드·제품·연구개발·지속가능경영·소식·채용 정보를 전달하는 기업 웹사이트 리뉴얼 프로젝트입니다.
- 메인 페이지는 브랜드 소개, 대표 제품 탐색, 기업 스토리, 이벤트, 가치 메시지, 채용 콘텐츠를 한 흐름으로 보여줍니다.
- 서브페이지는 메인에서 사용한 헤더·탐색·타이포그래피·컬러·콘텐츠 간격·버튼·푸터 규칙을 이어받아야 합니다.

### 디자인 방향
- **신뢰감 있는 기업형 디자인**을 바탕으로 동화약품의 대표 색상인 레드와 블루를 포인트로 사용합니다.
- 넓은 이미지와 충분한 여백으로 기업의 역사와 제품 이미지를 전달하고, 텍스트는 명확한 위계로 배치합니다.
- 둥근 CTA, 절제된 테두리, 정돈된 카드, 이미지 중심 섹션을 반복해 일관성을 만듭니다.
- 과도한 장식보다 정보 전달과 브랜드 인지, 다음 행동으로 이어지는 탐색성을 우선합니다.

### 기준 파일 및 우선순위
1. `DongWhaPharmaceutical/index.html`: 실제 콘텐츠 구조와 컴포넌트 클래스
2. `DongWhaPharmaceutical/css/main.css`: 메인 페이지의 주요 디자인 규칙 및 CSS 변수
3. `DongWhaPharmaceutical/css/neo-brutalism.css`: 별도 테마 실험용 스타일. 기본 디자인 규칙으로 사용하지 않습니다.
4. 상위 `css/default.css`: 전역 리셋, 기본 박스 모델, 이미지·폼·접근성 규칙
5. `../font/css/pretendardvariable.css`: Pretendard Variable 폰트 로드

**기본 디자인 판단 기준:** 현재 `index.html`의 `#wrap`에는 `neo-brutalism` 클래스가 없으므로, `neo-brutalism.css`의 `#wrap.neo-brutalism` 선택자는 기본 메인 화면에 적용되지 않습니다. 따라서 기본 서브페이지는 `main.css`의 브랜드 디자인을 따릅니다. 테마를 의도적으로 적용하는 별도 화면이 아니라면 Neo Brutalism의 원색·굵은 테두리·그림자 규칙을 가져오지 않습니다.

## 2. Brand Identity

### 브랜드 인상
- **핵심 인상:** 신뢰, 역사성, 건강, 안정감, 전문성.
- **주요 시각 요소:** 동화약품 로고, 레드 포인트, 딥 블루 보조색, 흰색 바탕, 짙은 차콜 텍스트.
- **이미지 사용:** 제품 패키지와 인물·자연·기업 관련 이미지를 넓게 배치합니다. 이미지 자체가 메시지를 전달하므로 불필요한 장식 프레임을 추가하지 않습니다.
- **강조 방식:** 모든 요소를 강한 색으로 강조하지 않고, 중요한 CTA·활성 상태·화살표 등에 브랜드 레드를 제한적으로 사용합니다.

### 로고 사용
- 메인 헤더와 푸터에서 동일한 `img/Logo.png`를 사용합니다.
- 로고는 원본 비율을 유지하고 임의로 늘이거나 색상을 변경하지 않습니다.
- 헤더에서는 가로형 로고를 주요 탐색보다 먼저 인지할 수 있도록 배치합니다.
- 서브페이지에서도 동일한 로고 파일과 상대 경로 체계를 사용합니다.

## 3. Design Principles

1. **메인 페이지와 같은 공통 틀:** 서브페이지마다 Header와 Footer를 새로 해석하지 말고 동일한 구조·높이·정렬·색상 규칙을 재사용합니다.
2. **정보 위계 우선:** 페이지 제목 → 핵심 설명 → 세부 콘텐츠 → 관련 CTA 순으로 읽히도록 구성합니다.
3. **레드 포인트의 절제:** 레드는 주요 행동과 핵심 강조에 사용하고 넓은 배경 전체를 레드로 채우지 않습니다.
4. **이미지 비율과 품질 유지:** 제품 이미지는 `contain`, 풍경·배너 이미지는 콘텐츠 목적에 따라 `cover`를 사용합니다.
5. **여백으로 구획:** 카드와 섹션을 모두 테두리로 나누기보다 섹션 패딩과 요소 간 간격으로 구분합니다.
6. **반복 컴포넌트 재사용:** 동일한 종류의 CTA·카드·링크는 같은 클래스와 상태 규칙을 사용합니다.
7. **접근성 유지:** 키보드 포커스 표시, 버튼의 명확한 이름, 이미지 대체 텍스트, 모바일 메뉴의 상태 전달을 유지합니다.
8. **기존 메인 페이지 보존:** 서브페이지 제작을 이유로 메인 페이지의 기존 HTML/CSS를 수정하거나 공통 스타일을 무리하게 덮어쓰지 않습니다. 공통 규칙 변경이 필요하다면 영향 범위를 먼저 확인합니다.

## 4. Color System

아래 값은 `main.css`의 `:root` 변수 및 실제 반복 사용된 색상에서 확인한 값입니다. 새 색상을 임의로 추가하지 말고 우선 기존 변수를 재사용합니다.

### 브랜드 CSS 변수

| CSS 변수 | 실제 값 | 사용 목적 |
|---|---|---|
| `--brand-primary` | `#ED1C24` | 주요 CTA, 강조 링크, 활성 페이지네이션, 포인트 아이콘 |
| `--brand-secondary` | `#194689` | 유틸리티 바, GNB 밑줄 등 보조 브랜드 포인트 |
| `--brand-white` | `#FFFFFF` | 기본 배경 및 흰색 표면 |
| `--text-primary` | `#231F20` | 기본 본문·제목 텍스트 |
| `--text-white` | `#FFFFFF` | 어두운 이미지 위 텍스트 |
| `--icon-black` | `#231F20` | 어두운 아이콘 |
| `--icon-white` | `#FFFFFF` | 밝은 아이콘 |
| `--border-default` | `#DDE1E7` | 헤더 하단선, 카드 테두리 등 기본 경계 |

### 호환 별칭 변수
기존 CSS와의 호환을 위해 다음 별칭이 정의되어 있습니다. 새 코드에서는 의미가 더 분명한 `--brand-*` 또는 `--text-*` 변수를 우선 사용하고, 기존 컴포넌트를 유지할 때는 별칭도 허용합니다.

| 별칭 | 연결 변수 |
|---|---|
| `--color-primary` | `var(--brand-primary)` |
| `--color-white` | `var(--brand-white)` |
| `--color-text` | `var(--text-primary)` |
| `--color-blue` | `var(--brand-secondary)` |

### 실제 사용된 보조 색상
다음 색상은 변수로 선언되어 있지 않지만 메인 CSS에서 직접 사용됩니다. 같은 역할이 필요할 때만 참고하고, 새 팔레트처럼 확장하지 않습니다.

| 값 | 확인된 사용 위치 / 역할 |
|---|---|
| `#F4B99F` | 브랜드 스토리 제목의 일부 강조 |
| `#F8F8F8` | 푸터 하단 정보 영역 배경 |
| `#5F636D`, `#626773`, `#4F4F4F` | 푸터의 보조 텍스트 |
| `#D9D9D9` | 푸터 구분선 |
| `#F7F7F7` | 이벤트 이미지 영역의 기본 배경 |
| `rgba(196, 196, 196, 0.1)` | 대표 제품 이미지 패널 배경 |
| `rgba(0, 0, 0, 0.15)` | 대표 제품 패널의 약한 그림자 |

### 적용 원칙
- 페이지 기본 표면은 흰색 계열로 유지합니다.
- 제목과 본문은 `--text-primary`를 사용합니다.
- 이미지 위 문구는 이미지 대비를 확인한 뒤 `--text-white`를 사용합니다.
- 주요 CTA는 레드 배경 + 흰색 글자 또는 흰색 배경 + 레드 테두리/글자 조합을 사용합니다.
- 블루는 보조 내비게이션·구조적 강조에 사용하고, 레드와 같은 강도로 모든 요소에 동시에 사용하지 않습니다.

## 5. Typography

### 폰트
- 기본 글꼴: `"Pretendard Variable", sans-serif`
- 로드 파일: `../font/css/pretendardvariable.css`
- 한글 본문과 UI에 동일한 글꼴 계열을 사용합니다.
- 별도 폰트를 추가하기 전에 기존 Pretendard Variable의 굵기 범위를 활용합니다.

### 메인 CSS에서 확인된 타이포그래피 기준

| 요소 / 용도 | 크기 | 굵기 | 행간 | 참고 |
|---|---:|---:|---:|---|

| GNB 링크 | 18px | 500 | 기본값 | 메인 탐색 |

| 대표 제품 섹션 제목 | 42px | 700 | 1.5 | 데스크톱 기준 |

| 브랜드 스토리 설명 | `clamp(14px, 1.25vw, 24px)` | 400 | 1.5 | 이미지 위 설명 |

| 건강 가치 본문 | 16px | 400 | 1.45 | 짧은 설명 |
| 채용 CTA | 15px | 400 | 1.3 | 이미지 배너 위 버튼 |
| 푸터 정보 | 10pt | 400 | 1.85 | 사업자·주소 등 정보 |

### 타이포그래피 적용 규칙
- 페이지의 대표 제목은 메인 Hero처럼 큰 크기와 높은 굵기를 사용하되, 모든 서브페이지 제목을 무조건 64px로 고정하지 않습니다. 콘텐츠 길이와 화면 너비에 맞춰 조정합니다.
- 섹션 제목은 700 굵기를 중심으로 사용합니다.
- 본문은 400~500 굵기를 중심으로 하며, 강조가 필요한 짧은 UI 텍스트만 600을 사용합니다.
- 한글 문장은 단어가 부자연스럽게 쪼개지지 않도록 상위 `default.css`의 `word-break: keep-all` 규칙을 유지합니다.
- 행간은 제목 1.2~1.5, 본문 약 1.45~1.5 등 실제 메인 CSS에서 사용한 값을 우선합니다. 새로운 고정 행간을 일괄 지정하지 않습니다.
- `clamp()`가 적용된 제목은 화면 너비에 따라 글자 크기가 자연스럽게 변하도록 유지합니다.

## 6. Layout & Spacing

### 컨테이너 너비
메인 페이지에는 콘텐츠 종류에 따라 서로 다른 최대 너비가 사용됩니다. 모든 서브페이지를 하나의 숫자로 강제하지 말고, 콘텐츠 성격에 맞는 기존 컨테이너 폭을 선택합니다.

| 용도 | 확인된 규칙 |
|---|---|
| 헤더 내부 | `width: min(1800px, calc(100% - 48px))` |
| Hero 텍스트 | `width: min(1720px, calc(100% - 48px))` |
| 대표 제품·이벤트·건강 가치 콘텐츠 | `width: min(1720px, 100%)` |
| 푸터 파트너 로고 | `width: min(1430px, 100%)` |
| 푸터 본문 | `width: min(1780px, 100%)` |
| 메가 메뉴 내부 | `width: min(640px, calc(100% - 48px))` |

### 섹션 여백
- 대표 제품 섹션: 데스크톱 `padding: 110px 20px`, 1024px 이하 `64px 16px`.
- 이벤트 섹션: 데스크톱 `100px 24px 110px`, 1024px 이하 `64px 16px 72px`.
- 건강 가치 섹션: 데스크톱 `100px 24px 24px`, 1024px 이하 `64px 16px 20px`.
- 푸터 본문: 데스크톱 `64px 24px 68px`, 1024px 이하 `40px 20px`.
- 브랜드 스토리 이미지는 화면 전체 폭을 사용하며 별도 좌우 패딩을 두지 않습니다.
- 채용 배너는 이미지가 주인공인 전체 폭 섹션이며, 내부 텍스트 그룹을 중앙 정렬합니다.

### 그리드와 Flex
- 헤더: `display: flex`로 로고·GNB·CTA를 한 줄에 정렬합니다. GNB는 중앙 기준으로 배치합니다.
- 대표 제품: 데스크톱에서 `478px minmax(0, 1fr)` 2열 Grid와 `86px` 간격을 사용합니다. 좁은 화면에서는 1열로 전환합니다.
- 이벤트: 데스크톱 3열 Grid, 1024px 이하 2열 Grid로 전환합니다.
- 건강 가치: 데스크톱에서는 이미지와 텍스트를 교차 배치하는 Grid 구조이며, 1024px 이하에서는 1열로 바꿉니다.
- 푸터: 데스크톱 3열 Grid(로고 / 회사 정보 / 링크), 1024px 이하 1열로 바꿉니다.
- 버튼 내부, 텍스트와 아이콘, 푸터 링크 그룹 등 한 방향 정렬에는 Flex를 사용합니다.
- Grid 자식이 넘치지 않도록 기존처럼 `minmax(0, 1fr)`, `min-width: 0`를 적극 사용합니다.

### 이미지 비율과 표시
- 제품 패키지: `object-fit: contain`으로 이미지 전체가 잘리지 않게 합니다.
- 이벤트 포스터: `aspect-ratio: 403 / 540`, 이미지 `object-fit: cover`.
- 건강 가치 이미지: `aspect-ratio: 1.9 / 1`, `object-fit: cover`.
- 브랜드 스토리: 이미지 너비 100%, 높이 자동으로 원본 비율을 유지합니다.
- 메인 비주얼: PC·모바일 이미지를 별도 제공하고, 보이는 이미지에 `object-fit: cover`를 적용합니다.

## 7. Components

### Header / GNB
- 공통 클래스: `.site-header`, `.header-utility`, `.header-main`, `.header-inner`, `.brand-logo`, `.main-nav`, `.header-actions`.
- 데스크톱 유틸리티 바는 높이 50px, 보조 블루(`--brand-secondary`) 배경, 오른쪽 정렬입니다.
- 메인 헤더는 높이 100px, 흰색 배경, 아래쪽 1px 기본 테두리입니다.
- 로고 이미지는 기본 너비 230px이며 비율을 유지합니다.

## 8. Interaction

### Hover
- GNB: 텍스트 색을 과도하게 바꾸기보다 블루 밑줄이 왼쪽에서 오른쪽으로 나타나도록 합니다(`transform: scaleX(1)`, 0.2s).
- GNB 메가 메뉴: 최대 높이와 투명도를 전환해 열고 닫습니다. 마우스가 GNB에서 메가 메뉴로 이동할 때 닫히지 않아야 합니다.
- 메가 메뉴 링크: 텍스트 굵기를 700으로 올려 현재 가리키는 항목을 구분합니다.
- 제품 이미지: Hover 시 `transform: scale(1.04)`, 0.25s.
- 이벤트 이미지: Hover 시 `transform: scale(1.025)`, 0.3s.
- 푸터 링크: 기본 텍스트에서 브랜드 레드로 변경합니다.
- 채용 CTA: 레드 배경·테두리로 전환합니다.

### Focus
- 키보드 사용자가 현재 위치를 알 수 있도록 `:focus-visible`을 유지합니다.
- 브랜드 스토리 링크: 흰색 2px outline, 5px offset.
- 건강 가치 링크: 레드 2px outline, 5px offset.
- 채용 CTA: 흰색 2px outline, 4px offset.
- 푸터 링크와 로고: 레드 2px outline, 4px offset.
- 상위 `default.css`의 전역 focus reset이 있으므로 컴포넌트별 `:focus-visible` 표시를 삭제하지 않습니다.
- 헤더·메뉴·제품 다음 버튼 등 다른 인터랙티브 요소에도 동일한 가시적 포커스 기준을 적용합니다.

### Active / Open
- GNB 선택 항목은 `.active` 클래스로 밑줄을 유지합니다.
- 메뉴 토글은 `aria-expanded=true/false`로 열림 상태를 전달합니다.
- 모바일 메뉴는 `hidden` 속성으로 표시 여부를 관리합니다.
- Swiper 페이지네이션 활성 bullet은 브랜드 레드로 표시합니다.

### Transition / Motion
- GNB 밑줄: 0.2s ease.
- 메가 메뉴: max-height 0.25s, opacity/visibility 0.2s.
- 헤더 CTA: 배경·테두리·글자색 0.2s.
- 제품 이미지: transform 0.25s.
- 이벤트 이미지: transform 0.3s.
- 상위 `default.css`는 `prefers-reduced-motion: reduce`를 지원합니다. 서브페이지에서도 모션 감소 설정을 무시하지 않습니다.

## 9. Responsive Rules

### 확인된 기본 브레이크포인트
- **1024px 이하:** `main.css`의 주요 반응형 전환점입니다.
- **600px / 600px 미만:** 제품 Swiper 설정에서 1개·2개 노출을 나누는 기준입니다.
- **1025px 이상:** JavaScript의 `desktopQuery`에서 데스크톱 메뉴 동작을 판단하는 기준입니다.
- `main.css`에서 별도의 600px 이하 전용 미디어쿼리는 확인되지 않았습니다. 서브페이지에 새로운 브레이크포인트가 필요하면 실제 콘텐츠가 깨지는 구간을 확인한 뒤 추가하고, 임의의 공통 규칙인 것처럼 문서화하지 않습니다.

### 1024px 이하에서 확인된 변경
- 헤더: sticky, 높이 72px, 유틸리티 바·GNB·메가 메뉴·헤더 CTA 숨김, 모바일 메뉴 토글 표시.
- 헤더 내부 좌우 폭: `calc(100% - 32px)`.
- 대표 제품: 2열에서 1열로 변경, 이미지 패널 너비 100%, 높이는 자동/최소 280px/최대 360px.
- 이벤트: 3열에서 2열로 변경, 섹션 패딩 축소, 카드 모서리 14px.
- 건강 가치: 이미지와 텍스트를 1열로 배치하고 텍스트의 초기 투명도·이동 상태를 해제해 콘텐츠가 보이도록 합니다.
- 푸터: 파트너 로고 줄바꿈, 구분선 숨김, 하단 정보 3열에서 1열로 변경.
- 채용 배너: 최소 높이 560px, 제목·버튼 크기 축소.
- 브랜드 스토리 카피: 상단 18%, 좌측 6% 기준으로 이동하고 텍스트 크기를 줄입니다.
- Hero: PC 이미지를 숨기고 모바일 이미지를 표시하며 텍스트 크기를 축소합니다.

### 서브페이지 반응형 적용
- 데스크톱의 다단 레이아웃은 1024px 이하에서 콘텐츠 우선순위에 따라 1열 또는 2열로 단순화합니다.
- 이미지와 텍스트가 좁은 폭에서 서로 밀어내지 않도록 Grid 자식에 `min-width: 0`을 사용합니다.
- 버튼과 링크는 터치 환경에서 눌러야 할 영역을 충분히 확보합니다.
- 모바일에서 데스크톱 GNB를 단순히 작게 줄이지 말고, 기존 모바일 메뉴 패턴을 사용합니다.
- 이미지의 핵심 피사체와 텍스트가 겹치지 않는지 실제 모바일 폭에서 확인합니다.

## 10. Do & Don't

### Do
- `main.css`의 `:root` 변수(`--brand-primary`, `--brand-secondary`, `--brand-white`, `--text-primary`, `--text-white`, `--border-default`)를 우선 사용합니다.
- Pretendard Variable을 기본 폰트로 사용합니다.
- 메인과 같은 Header / GNB / Footer 구조를 재사용합니다.
- 섹션 제목, 본문, 보조 정보의 크기와 굵기를 구분합니다.
- 콘텐츠 목적에 맞게 Grid와 Flex를 선택합니다.
- 제품 이미지는 `contain`, 포스터·배경 이미지는 필요에 따라 `cover`를 사용합니다.
- Hover뿐 아니라 키보드 Focus와 모바일 터치 상태도 확인합니다.
- 반응형 변경은 1024px 전후에서 먼저 검토하고, 실제 콘텐츠에 따라 보완합니다.
- 링크는 이 리뉴얼 프로젝트 안에서 동작하도록 구성합니다. 서브페이지 이동은 프로젝트 내부 상대 경로(예: `./product.html`, `./company.html`) 또는 해당 페이지 내부 앵커(`#section-id`)를 사용합니다.
- 외부 링크가 꼭 필요한 기능이 별도로 승인되지 않는 한, 동화약품 기존 공식 사이트나 기존 브랜드 사이트 URL로 연결하지 않습니다. 외부 사이트를 새 탭으로 여는 링크도 기본값으로 만들지 않습니다.

### Don't
- 기존 메인 페이지의 디자인을 바꾸기 위해 공통 CSS를 일괄 수정하지 않습니다.
- 기본 디자인 페이지에 Neo Brutalism의 노랑·라임·원색 블록, 3px 굵은 검정 테두리, 강한 그림자, 각진 버튼을 섞지 않습니다.
- 정의되지 않은 임의의 브랜드 컬러·폰트·그림자·모서리 수치를 새 기준인 것처럼 만들지 않습니다.
- 모든 섹션을 카드 박스나 테두리로 감싸지 않습니다.
- CTA마다 서로 다른 모서리·색상·높이를 사용하지 않습니다.
- 제품 패키지 이미지를 `cover`로 잘라 중요한 정보를 가리지 않습니다.
- 장식 목적의 애니메이션을 과도하게 추가하거나 포커스 표시를 제거하지 않습니다.
- `href="#"`만 넣어 실제 동작하지 않는 링크를 만들지 않습니다.
- 공식 동화약품 사이트 또는 기존 브랜드 사이트로 연결하는 URL을 새 서브페이지에 복사하지 않습니다.

## Implementation Notes / Current Repository Checks

아래 항목은 디자인 규칙과 별개로, 현재 저장소에서 확인된 구현 상태입니다. 메인 페이지를 임의로 수정하지 않도록 서브페이지 작업 전에 참고합니다.

1. `index.html`은 `../css/default.css`, Pretendard Variable, `css/main.css`, `css/neo-brutalism.css` 순서로 CSS를 불러옵니다. 마지막 Neo Brutalism CSS는 `#wrap.neo-brutalism` 범위에만 적용되므로 현재 `#wrap`에 해당 클래스가 없는 기본 상태에서는 적용되지 않습니다.
2. `main.css`의 `body`에는 `background-color: yellow;`가 직접 지정되어 있습니다. 메인 페이지의 실제 배경과 다르게 보이는 영역이 있다면 해당 선언과 각 섹션의 배경 지정 여부를 확인해야 합니다. 이 Design.md 작성 과정에서는 기존 CSS를 변경하지 않았습니다.
3. 현재 메인 HTML의 일부 링크는 공식 동화약품 도메인으로 연결되어 있습니다. 본 문서의 서브페이지 제작 규칙은 사용자의 요청에 따라 기존 브랜드 사이트로 연결하지 않고 프로젝트 내부 페이지·앵커를 사용하도록 정했습니다. 이 문서를 작성하면서 메인 HTML의 링크는 수정하지 않았습니다.
4. `index.html`에는 제품 슬라이더와 Hero 슬라이더를 위한 Swiper, 스크롤 애니메이션을 위한 GSAP/ScrollTrigger 스크립트가 포함되어 있습니다. 동일한 라이브러리 사용이 필요한 경우 현재 저장소의 로컬 파일 경로와 로딩 방식을 먼저 확인합니다.
5. 공통 CSS를 변경해야 하는 상황이라면 메인 페이지에 미치는 영향을 먼저 검토하고, 가능하면 서브페이지 전용 CSS에서 별도 클래스로 범위를 제한합니다.

---

**이 문서의 원칙:** 기존 메인 페이지가 디자인 기준이며, 서브페이지는 그 기준을 확장합니다. 수치나 색상이 CSS에서 확인되지 않으면 임의로 확정하지 말고 실제 화면과 소스에서 먼저 확인합니다.
